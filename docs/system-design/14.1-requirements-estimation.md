# 14.1 Requirements & Capacity Estimation

- **DAU**: 5 million active riders, 500,000 active drivers
- **GPS Pings**: 500,000 drivers emitting location every 4 seconds = 125,000 QPS telemetry ingress
- **Ride Requests**: 100,000 rides/hour peak = ~30 writes/sec
- **Network Bandwidth**: 125,000 QPS * 100 bytes = 12.5 MB/sec continuous ingress.
