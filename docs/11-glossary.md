# Technical Glossary

- **Socket.io**: A library enabling low-latency, bidirectional, event-based communication between clients and servers.
- **Geohash**: A public domain geocoding system that encodes a geographic location into a short string of letters and digits.
- **Distance Matrix API**: A Google service providing travel distance and time for a matrix of origins and destinations.
- **2dsphere Index**: A MongoDB index supporting queries that calculate geometries on an earth-like sphere.
- **OTP (One-Time Password)**: A cryptographic, single-use numeric code utilized for verification handshakes.
