# Frequently Asked Questions: UberRide Ride Booking Client & Dispatch

### 1. What is UberRide Ride Booking Client & Dispatch?
Ride-hailing booking interface with live driver simulation, route calculation, and fare estimations.

### 2. What technology stack does it use?
Built with Node.js (Express, MongoDB Atlas), React / JavaScript, Leaflet Maps.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/32-uber-clone/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
